# ملاحظات المطوّر

كيف بُني Keyboardless، وما القواعد التي يجب ألّا تُكسر، والدروس التي كلّفت جولات حقيقية.

## المعمارية في سطر واحد

```
مايك → رفع تلقائي (AGC) → Vosk (تعرّف متدفّق) → CommitEngine (تثبيت الكلمات) → كتابة في النافذة النشِطة
                     ↕ events
                النافذة / الأيقونة الجانبية
```

المحرّك (`ar_dictate.py`) **بلا واجهة**: لا يطبع شيئًا تعتمد عليه الواجهة، بل يُطلق أحداثًا
(`state` · `typed` · `partial` · `meter` · `log` · `listening` · `error` · `device-fallback`) عبر
`Dictation.on_event`. النافذة تشترك فيها، وسطر الأوامر يتركها فارغة. النتيجة: عطل في الواجهة
لا يمكن أن يُسكت الإملاء.

| الوحدة | مسؤوليتها |
|---|---|
| `ar_dictate.py` | التعرّف، الاختصارات (pynput بمطابقة **رمز المفتاح**)، الحقن، الإعدادات، أوامر الطرفية |
| `streaming.py` | `CommitEngine`: لا تُكتب الكلمة إلا بعد اتفاق نتيجتين متتاليتين (LocalAgreement-2)، مع إغلاق المقطع عند الصمت |
| `inject_win.py` | `SendInput` (unicode + سطر جديد = Enter) أو الحافظة؛ و`target_info` لتسجيل النافذة المستهدفة |
| `postprocess.py` | الترقيم العربي، الأوامر الصوتية («فاصلة» → ،)، إصلاحات اللهجة |
| `gui.py` | النافذة والأيقونة الجانبية؛ طبقة رقيقة فوق المحرّك |
| `app_icons.py` | حالات الأيقونة الأربع، أي حالة متى، وبناء `.ico` متعدّد المقاسات |
| `app_theme.py` | المظهر الفاتح/الداكن وألوان دليل التصميم |
| `model_store.py` | تنزيل النماذج مع الاستكمال ورفض الأرشيف غير الآمن |
| `branding.py` | الاسم والإصدار والمؤلف والإهداء — **مصدر واحد** |

## قواعد لا تُكسر

1. **الاختصارات تُقرأ من `app/config.json` فقط.** لا تُكتب في `.cmd` ولا في اختبار ولا في بانر؛
   اختبار يفشل إن ظهر حرف اختصار في أي أداة.
2. **الإعداد مصدر واحد.** النافذة وسطر الأوامر يكتبان ويقرآن نفس الملف، وأي مفتاح يُحفظ عبر
   `update_config_keys` (يتحقّق من حقول الاختصارات فقط، والباقي كما هو).
3. **مسارات المهمة تُحسب نسبةً لملف الإعداد** لا لمجلد الإطلاق (سبب تاريخي لموت صامت).
4. **النسخة المثبَّتة لا تكتب في مجلد تثبيتها:** كل ما هو للكتابة في `%LOCALAPPDATA%\Keyboardless`.
5. **المحرّك لا ينهار على جهاز صوت فاشل:** يبلّغ، ثم **يرجع للمايك الافتراضي**، ثم يحاول.
6. **الأرشيف المنزَّل مدخل غير موثوق:** يُرفض أي مدخل يحاول الكتابة خارج مجلد النماذج.
7. **الأيقونات:** 16/20/24 مرسومة يدويًا ولا تُصغَّر من 256؛ العلبة أحادية في الوضع الداكن؛ وملف
   `.ico` يجمع 16/20/24/32/48/256.
8. **انشر المحرّك كوحدة:** ملف واحد جديد مع ملفات مساعدة قديمة = انهيار عند أول كلمة مثبَّتة.
   `app/tests/sync_deploy.py` ينشر بالتحقّق بالبصمة ويفشل بصوت عالٍ.

## الاختبارات

```bash
python -m unittest discover -s app/tests        # أكثر من 200 اختبارًا
```

اختبارات تحرس أخطاء وقعت فعلًا:

| الاختبار | الخطأ الذي يمنعه |
|---|---|
| `test_engine_contract.py` | نشر نصف محرّك (واجهات ناقصة بين الوحدات) |
| `test_model_store.py` | اسم نموذج معقول لكنه 404، وأرشيف بمسار تصعيدي، وانقطاع تنزيل |
| `test_launcher.py` / `test_branding.py` | اختفاء نهايات CRLF، أو رجوع الاسم القديم في واجهة |
| `test_packaging.py` | ملف `.iss` بمعرّف غير صالح، أو نسخة مثبّت لا تطابق نسخة البرنامج، أو سطر يبدأ بـ`#` |
| `test_theme.py` | مظهر غير مقروء (تباين الإهداء) أو خيار مفقود |
| `test_icons.py` | مقاس أيقونة مُصغَّر آليًا بدل النسخة اليدوية |

## التغليف

```powershell
powershell -ExecutionPolicy Bypass -File app\packaging\build_windows.ps1 -Installer
```

- **PyInstaller** (`app/packaging/keyboardless.spec`): ملف تنفيذي واحد نافذي-الوجهين (نافذة +
  `--cli`)، مع `collect_all` لـ`vosk` و`sounddevice` (بدونها يشتغل البرنامج ثم يموت عند أول
  استيراد)، واستثناءات تُسقط ما لا يُستعمل — منها `opengl32sw.dll` وترجمات Qt (وفّرت ~26 ميجابايت).
  **النموذج لا يُضمَّن** (يبقى المثبّت 39 ميجابايت).
- **أيقونة ويندوز**: `make_icon.py` يبني `.ico` متعدّد المقاسات من صور التصميم ويتحقّق أنه كتبها.
- **Inno Setup** (`app/packaging/keyboardless.iss`): تثبيت في مجلد المستخدم بلا صلاحيات مدير، بلا
  أسئلة (لا صفحة مسار ولا مجموعات)، وينزّل النموذج تلقائيًا مع `Check: ModelMissing` فلا يُنزّله
  مرتين، ويحذف النموذج عند الإلغاء.

### مزالق Inno Setup التي وقعت فعلًا

- ملف `.iss` فيه عربي **يحتاج تكرار الرقم** بينه وبين `branding.VERSION`، واختبار يمنع افتراقهما.
- سطر يبدأ بـ`#` يُقرأ **تعليمة معالج مسبق**: `#13#10` وحده في سطر يوقف التصريف برسالة غامضة.
- `#` داخل قيمة `#define` حرف غير مسموح أصلًا.
- Inno Setup عبر winget يُثبَّت في `%LOCALAPPDATA%\Programs\Inno Setup 6` لا في Program Files.

### مزالق PowerShell (ويندوز)

- ملف `.ps1` فيه عربي **يجب أن يبدأ ببصمة UTF-8 (BOM)** وإلا قرأه PowerShell 5.1 بترميز قديم
  فتشوّه النص وانكسر التفسير. اختبار يحرس كل ملفات `.ps1`.
- **لا تكتب PowerShell سطريًا عبر SSH**: `cmd` يفسّر `|` و`"` داخل الأمر. اكتب ملف `.ps1` وشغّله.
- مسبار يعمل في جلسة مجدولة قد يعمل بمستخدم آخر فلا يقرأ مجلد `AppData` للمستخدم الحقيقي — ويظهر
  ذلك «صفرًا» بصمت. كل مسبار يطبع `whoami` ويُبلّغ عن أخطاء القراءة.

## أدوات التشخيص

| الأداة | ما تجيب عنه |
|---|---|
| `--cli --mic-level 5` | هل يصل صوت، بأي مستوى، وبأي كسب، وما النص المُفهوم |
| `--cli --check-hotkeys` | هل المفتاح محجوز لبرنامج آخر (`free` / `TAKEN`) |
| `--cli --models` · `--cli --verify-urls` | حالة النماذج وصحّة روابطها |
| `app/tests/sync_deploy.py` | نشر المشروع لجهاز مع التحقّق بالبصمة |
| `app/tests/exe_probe.ps1` · `install_probe.ps1` | فحص النسخة المبنيّة والمثبّتة |
| `app/tests/run_probe_interactive.ps1` | تشغيل أي مسبار داخل جلسة سطح المكتب (الاختصارات تحتاج جلسة تفاعلية) |

## قيود وخطط

- النموذج الافتراضي على المعالج يعمل أسرع من الزمن الحقيقي (RTF ≈ 0.43–0.5)؛ النماذج الكبيرة أبطأ
  من الكلام، ولهذا وُسمت في الواجهة.
- اللغة: الفصحى واللهجة السعودية حاليًا؛ إضافة نموذج عربي آخر = تنزيل جديد من تبويب «النماذج».
- macOS/Linux خارج النطاق حاليًا (الحقن والاختصارات مكتوبة لويندوز).
